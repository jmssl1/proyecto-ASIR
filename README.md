# proyecto-ASIR
Documentación del proyecto de PIMA (1º ASIR)
Somos una empresa de gestión de redes en empresas privadas como un hotel.
Algunos problemas de la empresa son tener los dispositivos desactualizados, dificultad para instalar la red en una zona determinada y la página web del hotel está desactualizada.
El repositorio sirve para tener guardados los proyectos de la empresa de manera centralizada.
Autores: Juanma Sánchez y Pedro Romero.
